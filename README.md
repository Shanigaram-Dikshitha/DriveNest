# DriveNest

DriveNest is a responsive second-hand vehicle selling website built using React and Vite.

## Features

- Vehicle search
- Vehicle filtering and sorting
- Vehicle details
- Favorites
- Compare vehicles
- Sell vehicle
- Login and Register
- Forgot Password
- User Dashboard
- Edit Profile
- Contact Seller
- Responsive design
- Mock authentication
- Browser localStorage

## Technologies

- React
- JavaScript
- HTML
- CSS
- Vite
- React Router

## Run Project

```bash
npm install
npm run dev
```
